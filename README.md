# StarTrunk System for Roblox

StarTrunk System transforms vehicle trunks into interactive 3D spaces with real props, physics, and animations. It works seamlessly with various Roblox frameworks and inventory systems, providing a realistic and immersive experience for players.

## Installation

1. Place the `StarTrunkSystem.server.lua` script in the `ServerScriptService`.
2. Configure the system by editing the `Config` table in the script.

## Usage

1. Call `StarTrunkSystem:Init()` to initialize the system.
2. Use `StarTrunkSystem:OpenTrunk(player, vehicle)` to open a trunk.
3. Use `StarTrunkSystem:CloseTrunk(player, vehicle)` to close a trunk.
